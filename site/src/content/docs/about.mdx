openusd.dev helps developers compare OUSD providers and find integration docs.

## Maintainer

Maintained by **Paul Copplestone**. This is a personal project, not a Supabase product. It is not affiliated with or endorsed by Open Standard or the providers listed here.

[Tweet at Paul](https://x.com/kiwicopple).

## Sources and review dates

We use official product docs and provider announcements. Each directory record links to the source for its claim. Provider participation does not establish product access; network deployment does not establish account eligibility.

- **Reviewed:** when the source or claim was checked.
- **Modified:** when the record changed.
- **Unknown:** not established by the sources reviewed, not unsupported.

No provider integration has been independently tested for this site. A tested label requires a dated test artifact; provider review requires recorded confirmation. Builds do not refresh review dates.

Paul is responsible for editorial maintenance. Access claims should be reviewed monthly and after relevant provider releases. Monitoring is manual; no bot publishes changes.
